# `ydk catalog`

```text
                                                                                
 Usage: ydk catalog [OPTIONS] COMMAND [ARGS]...                                 
                                                                                
 Browse and manage the YDK catalog                                              
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ search     Search the catalog for items.                                     │
│ install    Install a catalog item into the current project.                  │
│ list       List items installed in the current project.                      │
│ info       Show details about a catalog item.                                │
│ publish    Publish a catalog item (validate + copy to local catalog).        │
│ uninstall  Remove a catalog item from the current project.                   │
╰──────────────────────────────────────────────────────────────────────────────╯
```

## `ydk catalog search`

```text
                                                                                
 Usage: ydk catalog search [OPTIONS] QUERY                                      
                                                                                
 Search the catalog for items.                                                  
                                                                                
╭─ Arguments ──────────────────────────────────────────────────────────────────╮
│ *    query      TEXT  Search query [required]                                │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --tag       -t      TEXT  Filter by tag                                      │
│ --semantic  -s            Use semantic search (requires ChromaDB)            │
│ --help                    Show this message and exit.                        │
╰──────────────────────────────────────────────────────────────────────────────╯
```
