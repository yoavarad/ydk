# `ydk change`

```text
                                                                                
 Usage: ydk change [OPTIONS] COMMAND [ARGS]...                                  
                                                                                
 Spec evolution — propose, track, and archive changes                           
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ propose  Create a new change proposal with templates.                        │
│ list     List changes filtered by status.                                    │
│ status   Show artifact completeness for a change.                            │
│ archive  Archive a change: merge delta specs into canonical specs.           │
│ diff     Preview what archiving would do (without applying).                 │
╰──────────────────────────────────────────────────────────────────────────────╯
```

## `ydk change propose`

```text

│ --mode  -m      TEXT  Change mode: major or small [default: small]           │
```
