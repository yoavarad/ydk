# `ydk todo`

```text
                                                                                
 Usage: ydk todo [OPTIONS] COMMAND [ARGS]...                                    
                                                                                
 Manage ignition TODOs                                                          
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ list          List all TODOs with status.                                    │
│ show          Show details of a specific TODO.                               │
│ assign        Link a TODO to a task.                                         │
│ done          Mark TODO as done. Verifies NotImplementedError is removed.    │
│ assign-batch  Bulk assign TODOs to tasks. Accepts                            │
│               'YDK-TODO-001:T-001,YDK-TODO-002:T-001' or a YAML file.        │
│ auto-assign   Auto-assign TODOs to tasks by matching file paths to task      │
│               component_refs.                                                │
│ coverage      Show TODO completion coverage.                                 │
╰──────────────────────────────────────────────────────────────────────────────╯
```
