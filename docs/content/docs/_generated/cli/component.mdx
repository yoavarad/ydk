# `ydk component`

```text
                                                                                
 Usage: ydk component [OPTIONS] COMMAND [ARGS]...                               
                                                                                
 Component manifest management                                                  
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ list          List all components, optionally filtered by type.              │
│ show          Show a component manifest.                                     │
│ create        Create a new component from a schema template.                 │
│ validate      Validate ALL components (schema + linker + cross-refs).        │
│ list-schemas  List available schemas.                                        │
│ show-schema   Show a schema definition.                                      │
│ init-schemas  Copy default schemas to project's .ydk/schemas/ directory.     │
╰──────────────────────────────────────────────────────────────────────────────╯
```
