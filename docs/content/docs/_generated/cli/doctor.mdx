# `ydk doctor`

Run health checks on the YDK environment to verify all required tools, configurations, and dependencies are properly set up.

```text
 Usage: ydk doctor [OPTIONS]

╭─ Options ────────────────────────────────────────────────────────────────────╮
│    --help           Show this message and exit.                              │
╰──────────────────────────────────────────────────────────────────────────────╯
```

## Usage

```bash
$ ydk doctor
YDK Doctor - Environment Health Check

[PASS] Python >= 3.11 (3.12.4)
[PASS] YDK installed (v2.1.0)
[PASS] .ydk/ directory exists
[PASS] config.yaml valid
[PASS] ChromaDB available
[PASS] ruff installed (0.8.2)
[PASS] ty installed (0.1.5)
[PASS] pytest installed (8.3.4)
[PASS] git configured (user.name, user.email set)
[PASS] Catalog path exists (~/.ydk/catalog/)
[WARN] No ignition pack installed -- run `ydk catalog install <pack>`

10 passed, 1 warning, 0 failed
```

The doctor command checks:

- Python version compatibility
- YDK installation and version
- Project configuration validity
- Required tools (ruff, ty, pytest, git)
- Catalog and ChromaDB availability
- Installed pack status
- LaunchAgent status (if watch was configured)
