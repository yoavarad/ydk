# `odk memory`

```text
                                                                                
 Usage: odk memory [OPTIONS] COMMAND [ARGS]...                                  
                                                                                
 Knowledge management and memory                                                
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ index             Build/rebuild ChromaDB index from project knowledge files. │
│ search            Semantic search across all project knowledge.              │
│ bootstrap         Assemble relevant memories for a task.                     │
│ extract           Extract learnings from a completed task's transcript.      │
│ get               Retrieve full details for a specific memory by ID.         │
│ record-decision   Show the current (latest) decision for a topic.            │
│ decision-history  Show all versions of a decision for a topic (newest        │
│                   first).                                                    │
│ retrospective     Sprint retrospective — aggregate learnings across tasks    │
│                   using LLM analysis.                                        │
│ audit             Comprehensive memory health audit -- stale research,       │
│                   duplicates, and procedural reports.                        │
│ consolidate       Find and merge duplicate memories.                         │
╰──────────────────────────────────────────────────────────────────────────────╯
```
