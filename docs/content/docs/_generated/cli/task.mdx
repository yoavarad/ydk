# `ydk task`

```text
                                                                                
 Usage: ydk task [OPTIONS] COMMAND [ARGS]...                                    
                                                                                
 Task management and validation                                                 
                                                                                
 Lifecycle: start -> done -> (merge) -> close. `start` opens a worktree, `done` 
 opens the PR, and `close` reconciles one task to done once its PR is merged.   
 Use `sync` to reconcile all open/in-review tasks in bulk.                      
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ create                Create a new task.                                     │
│ create-batch          Create epics, stories, and tasks from a YAML file      │
│                       using two-pass dependency resolution.                  │
│ migrate               Migrate local epics, stories and tasks to GitHub       │
│                       issues.                                                │
│ start                 Start a task: create worktree, claim, explore.         │
│ comment               Post comment to task issue (replaces plan and          │
│                       progress).                                             │
│ block                 Mark task as blocked.                                  │
│ unblock               Resume a blocked task.                                 │
│ done                  Complete task: verify, create PR, post proof.          │
│ add-gate              Add an external event gate to a task.                  │
│ check-gates           Check all gates on a task.                             │
│ resolve-gate          Manually resolve a human gate.                         │
│ add-subtask           Create discovered subtask linked to parent.            │
│ ready                 List all actionable tasks with satisfied dependencies, │
│                       ranked by priority.                                    │
│ sync-issues           Retire linked external issues whose YDK tasks are all  │
│                       closed.                                                │
│ list                  List tasks with optional filters, grouped by status.   │
│ epics                 List epics with status and progress (done/total        │
│                       tasks).                                                │
│ stories               List stories with status and progress (done/total      │
│                       tasks), optionally filtered by epic.                   │
│ validate-dag          Validate task dependency graph (DAG) -- reads tasks    │
│                       from repository.                                       │
│ component-coverage    Check that every component manifest is referenced by   │
│                       at least one task.                                     │
│ plan-waves            Display resource-constrained schedule as a table --    │
│                       reads tasks from repository.                           │
│ coverage              Check spec-to-story coverage.                          │
│ analyze-complexity    Score task complexity (1-10) using LLM analysis.       │
│ archive-done          Archive completed tasks into context-efficient         │
│                       summaries.                                             │
│ create-epic           Create a new epic.                                     │
│ create-story          Create a new story.                                    │
│ quick                 Set up a lightweight workspace for a small change.     │
│ tdd                   Set TDD phase on task (stored in frontmatter).         │
│ review-comments       Fetch unresolved PR review comments for a task.        │
│ close                 Reconcile a task's status to done based on its PR's    │
│                       merge state.                                           │
│ sync                  Bulk-reconcile open/in-review tasks' status against    │
│                       their PRs' merge state.                                │
│ scaffold-batch        Generate a batch YAML template from existing TODOs,    │
│                       grouped by service.                                    │
│ merge-driver          Git merge driver: deterministically merge YDK          │
│                       bookkeeping files.                                     │
│ install-merge-driver  Register the bookkeeping merge driver in git config    │
│                       and .gitattributes.                                    │
╰──────────────────────────────────────────────────────────────────────────────╯
```

## `ydk task close`

```text
                                                                                
 Usage: ydk task close [OPTIONS] TASK_ID                                        
                                                                                
 Reconcile a task's status to done based on its PR's merge state.               
                                                                                
 Run this AFTER the task's PR is merged. Status does NOT auto-update on         
 merge: `ydk task done` only sets in-review, so this command is what moves      
 a task to done and unblocks its dependents. It is also the recovery path       
 for a task stuck at open or in-review (e.g. a session died before              
 `ydk task done` finished).                                                     
                                                                                
 It looks up the task's PR by branch via `gh`. If the PR is merged, the         
 task becomes done. If the PR is open or closed-unmerged, it reports the        
 state and changes nothing (exit 0). If no PR is found, it errors (exit 1).     
                                                                                
 For a task with no PR of its own (duplicate, or covered by another task        
 or PR), pass --delivered-by and/or --reason (either alone is enough). The      
 PR lookup is skipped, an audit comment is recorded on the task, and the        
 task is marked done. An unknown --delivered-by task id errors before any       
 change.                                                                        
                                                                                
 When the closed task was the last open one in its story, the story is          
 closed too; when it was the last in its epic, the epic is closed and           
 "Epic ... complete" is printed with the retrospective next step.               
                                                                                
 To reconcile many tasks at once, use `ydk task sync`.                          
                                                                                
                                                                                
 Examples:                                                                      
   ydk task close T-a1b2c3d4                                                    
   ydk task close T-a1b2c3d4 --delivered-by T-e5f6a7b8 --reason "dup"           
                                                                                
╭─ Arguments ──────────────────────────────────────────────────────────────────╮
│ *    task_id      TEXT  Task ID to close; set to done only if its PR is      │
│                         merged (or a no-PR flag is given)                    │
│                         [required]                                           │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --delivered-by        TEXT  Task id, PR URL, or PR number that delivered     │
│                             this work (closes a task with no PR of its own)  │
│ --reason              TEXT  Why the task is closed without its own PR (e.g.  │
│                             'dup of T-012'); recorded in the audit comment   │
│ --help                      Show this message and exit.                      │
╰──────────────────────────────────────────────────────────────────────────────╯
```

```text
                                                                                
 Usage: ydk task sync [OPTIONS]                                                 
                                                                                
 Bulk-reconcile open/in-review tasks' status against their PRs' merge state.    
                                                                                
 This is the bulk version of `ydk task close`. Prefer `ydk task close <id>` to  
 reconcile a single task, or to close a task that has no PR of its own. Prefer  
 `ydk task sync` to sweep every open/in-review task at once. Like close, it     
 closes stories/epics whose last task it marks done, and also sweeps for any    
 story/epic left open even though all its children are already done.
```
