# `odk task`

```text
                                                                                
 Usage: odk task [OPTIONS] COMMAND [ARGS]...                                    
                                                                                
 Task management and validation                                                 
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ create              Create a new task.                                       │
│ create-batch        Create epics, stories, and tasks from a YAML file using  │
│                     two-pass dependency resolution.                          │
│ start               Start a task: create worktree, claim, explore.           │
│ comment             Post comment to task issue (replaces plan and progress). │
│ block               Mark task as blocked.                                    │
│ unblock             Resume a blocked task.                                   │
│ done                Complete task: verify, create PR, post proof.            │
│ add-gate            Add an external event gate to a task.                    │
│ check-gates         Check all gates on a task.                               │
│ resolve-gate        Manually resolve a human gate.                           │
│ add-subtask         Create discovered subtask linked to parent.              │
│ ready               List all actionable tasks with satisfied dependencies,   │
│                     ranked by priority.                                      │
│ list                List tasks with optional filters, grouped by status.     │
│ validate-dag        Validate task dependency graph (DAG) -- reads tasks from │
│                     repository.                                              │
│ component-coverage  Check that every component manifest is referenced by at  │
│                     least one task.                                          │
│ plan-waves          Display resource-constrained schedule as a table --      │
│                     reads tasks from repository.                             │
│ coverage            Check spec-to-story coverage.                            │
│ analyze-complexity  Score task complexity (1-10) using LLM analysis.         │
│ archive-done        Archive completed tasks into context-efficient           │
│                     summaries.                                               │
│ create-epic         Create a new epic.                                       │
│ create-story        Create a new story.                                      │
│ quick               Set up a lightweight workspace for a small change.       │
│ tdd                 Set TDD phase on task (stored in frontmatter).           │
│ review-comments     Fetch unresolved PR review comments for a task.          │
╰──────────────────────────────────────────────────────────────────────────────╯
```

## `odk task create-batch`

```text
                                                                                
 Usage: odk task create-batch [OPTIONS]                                         
                                                                                
 Create epics, stories, and tasks from a YAML file using two-pass dependency    
 resolution.                                                                    
                                                                                
 The YAML file supports top-level ``epics``, ``stories``, and ``tasks`` keys.   
 Each entity has an ``id`` field used for cross-referencing within the file.    
 Task dependencies are resolved to real IDs after all issues are created.       
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ *  --from           TEXT  YAML file with batch definitions [required]        │
│    --dry-run              Validate and show what would be created without    │
│                           calling the API                                    │
│    --help                 Show this message and exit.                        │
╰──────────────────────────────────────────────────────────────────────────────╯
```
