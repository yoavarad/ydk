# `ydk ignite`

```text
                                                                                
 Usage: ydk ignite [OPTIONS]                                                    
                                                                                
 Generate project skeleton from installed ignition pack and YDK components.     
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --dry-run              Show what would be generated without writing          │
│ --force                Regenerate all files, even developer-owned            │
│ --skip-verify          Skip spec verification gate (for brownfield/inherited │
│                        specs)                                                │
│ --help                 Show this message and exit.                           │
╰──────────────────────────────────────────────────────────────────────────────╯
```
