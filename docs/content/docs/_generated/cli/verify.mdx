# `ydk verify`

```text
                                                                                
 Usage: ydk verify [OPTIONS] COMMAND [ARGS]...                                  
                                                                                
 Run verification checks                                                        
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ run          Run verification plugins.                                       │
│ pr-body      Validate a PR body with the pr-body-validation plugin.          │
│ check-guard  Run guard plugins for real-time enforcement. Reads context from │
│              stdin.                                                          │
│ list         List all discovered verification plugins.                       │
│ create       Create a new project-specific verification plugin.              │
│ clear-cache  Clear the verification result cache.                            │
╰──────────────────────────────────────────────────────────────────────────────╯
```

## `ydk verify run`

```text
                                                                                
 Usage: ydk verify run [OPTIONS]                                                
                                                                                
 Run verification plugins.                                                      
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --name               TEXT     Run only this plugin                           │
│ --trigger            TEXT     Filter by trigger ID (e.g. git:pre-commit)     │
│ --auto-fix                    Auto-fix violations before checking            │
│ --no-cache                    Bypass the verification cache                  │
│ --retry              INTEGER  Retry verification up to N times on failure    │
│ --repair                      Alias for --retry 3                            │
│ --save-proof                                                                 │
│ --task-id            TEXT                                                    │
│ --pr                 TEXT     PR URL — post results as a PR comment          │
│ --capture                     Capture verification output to proof files     │
│ --skip-plugin        TEXT     Skip a plugin by name (repeatable)             │
│ --help                        Show this message and exit.                    │
╰──────────────────────────────────────────────────────────────────────────────╯
```
