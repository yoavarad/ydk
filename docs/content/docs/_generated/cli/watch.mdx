# `ydk watch`

```text
                                                                                
 Usage: ydk watch [OPTIONS] COMMAND [ARGS]...                                   
                                                                                
 GitHub PR comment watcher                                                      
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ install    Install macOS launchd plist for 30-second polling.                │
│ uninstall  Remove the launchd plist and stop the watcher.                    │
│ poll       Check for new PR review comments and trigger agent sessions.      │
│ status     Show watcher status: installed?, last poll, active sessions.      │
╰──────────────────────────────────────────────────────────────────────────────╯
```
