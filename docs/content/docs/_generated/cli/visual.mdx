# `odk visual`

```text
                                                                                
 Usage: odk visual [OPTIONS] COMMAND [ARGS]...                                  
                                                                                
 Browser-based design annotation companion                                      
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ start       Start a new visual companion session.                            │
│ stop        Stop a running visual companion session.                         │
│ push        Push content to a visual companion session.                      │
│ feedback    Read feedback events from a visual companion session.            │
│ screenshot  Capture a screenshot of a visual companion page.                 │
│ list        List all visual companion sessions.                              │
│ record      Record a video of a page or browser flow using Playwright.       │
╰──────────────────────────────────────────────────────────────────────────────╯
```

## `odk visual record`

```text
                                                                                
 Usage: odk visual record [OPTIONS]                                             
                                                                                
 Record a video of a page or browser flow using Playwright.                     
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ *  --url           -u      TEXT     URL to record [required]                 │
│    --actions-file  -a      PATH     JSON actions list                        │
│    --output        -o      PATH     Output dir for video                     │
│                                     [default: .odk/proofs/latest]            │
│    --wait                  INTEGER  Wait time in ms (used when no actions    │
│                                     file)                                    │
│                                     [default: 3000]                          │
│    --help                           Show this message and exit.              │
╰──────────────────────────────────────────────────────────────────────────────╯
```
