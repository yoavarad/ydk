# `odk scaffold`

```text
                                                                                
 Usage: odk scaffold [OPTIONS] COMMAND [ARGS]...                                
                                                                                
 Generate files from templates                                                  
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ list    List all available templates.                                        │
│ info    Show template manifest (description + variables).                    │
│ apply   Generate files from a template.                                      │
│ create  Create a new project-specific template.                              │
╰──────────────────────────────────────────────────────────────────────────────╯
```
