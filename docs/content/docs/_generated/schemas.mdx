# Component Schemas

These schemas define the structure of ODK component manifests.
Each component YAML file in `.odk/components/` must conform to its schema.

## `component` (v1)

A reusable UI component with props, state, and rendering rules

```yaml
name: component
description: "A reusable UI component with props, state, and rendering rules"
version: 1
fields:
  id:
    type: string
    required: true
    pattern: "^odk:component:.+"
    description: "Unique component identifier in odk:component:namespace/name format"
  description:
    type: text
    required: true
    description: "What this UI component renders and its purpose"
  type:
    type: enum
    values: [table, form, card, modal, chart, layout, input, display]
    required: true
    description: "Component archetype"
  framework:
    type: enum
    values: [react, vue, svelte, angular, agnostic]
    required: true
    description: "Target frontend framework"
  props:
    type: map
    required: true
    description: "Component props/inputs keyed by prop name"
    items:
      type:
        type: string
        required: true
        description: "TypeScript type signature"
      required:
        type: boolean
        description: "Whether this prop is required"
      default:
        type: any
        description: "Default value if not provided"
      description:
        type: string
        required: true
        description: "What this prop controls"
  columns:
    type: list
    description: "For table components: column definitions"
  data_source:
    type: ref
    ref_type: route
    description: "API route this component fetches data from"
  pagination:
    type: string
    description: "Pagination strategy (cursor-based, offset, none)"
  default_sort:
    type: map
    description: "Default sort configuration"
  emits:
    type: list
    description: "Events this component emits (for parent components to handle)"
```

## `entity` (v1)

A domain model / data object with fields, relationships, and lifecycle

```yaml
name: entity
description: "A domain model / data object with fields, relationships, and lifecycle"
version: 1
fields:
  id:
    type: string
    required: true
    pattern: "^odk:entity:.+"
    description: "Unique component identifier in odk:entity:namespace/Name format"
  description:
    type: text
    required: true
    description: "What this entity represents in the domain"
  fields:
    type: map
    required: true
    description: "All fields on this entity, keyed by field name"
    items:
      type:
        type: string
        required: true
        description: "Data type (UUID, string, integer, Decimal, datetime, enum, boolean)"
      required:
        type: boolean
        description: "Whether the field is required on creation"
      nullable:
        type: boolean
        description: "Whether the field can be null"
      primary_key:
        type: boolean
        description: "Whether this field is the primary key"
      generated:
        type: boolean
        description: "Whether the value is server-generated"
      fk:
        type: ref
        ref_type: entity
        description: "Foreign key reference to another entity"
      max_length:
        type: integer
        description: "Maximum string length"
      precision:
        type: list
        description: "Decimal precision as [total_digits, decimal_places]"
      default:
        type: any
        description: "Default value if not provided"
      constraints:
        type: string
        description: "Additional validation constraints in human-readable form"
      values:
        type: list
        description: "Allowed values for enum fields"
      auto:
        type: boolean
        description: "Whether the value is automatically set (e.g., timestamps)"
      description:
        type: string
        required: true
        description: "What this field represents"
  state_transitions:
    type: map
    description: "Valid state transitions keyed by source state, values are lists of target states"
  relationships:
    type: list
    description: "Relationships to other entities"
    items:
      entity:
        type: ref
        ref_type: entity
        required: true
        description: "The related entity ID"
      type:
        type: enum
        values: [one-to-one, one-to-many, many-to-one, many-to-many]
        required: true
        description: "Cardinality of the relationship"
      fk:
        type: string
        required: true
        description: "Foreign key field name on this entity"
      description:
        type: string
        required: true
        description: "What this relationship represents"
  indexes:
    type: list
    description: "Database indexes for query optimization"
    items:
      fields:
        type: list
        required: true
        description: "Fields included in this index"
      order:
        type: list
        description: "Sort order per field (ASC or DESC)"
      unique:
        type: boolean
        description: "Whether this is a unique index"
      description:
        type: string
        required: true
        description: "Why this index exists (which query pattern it supports)"
  crud:
    type: list
    description: "Required CRUD operations for this entity's repository"
```

## `route` (v1)

An API endpoint with method, path, request/response shapes, and auth rules

```yaml
name: route
description: "An API endpoint with method, path, request/response shapes, and auth rules"
version: 1
fields:
  id:
    type: string
    required: true
    pattern: "^odk:route:.+"
    description: "Unique component identifier in odk:route:namespace/name format"
  description:
    type: text
    required: true
    description: "What this endpoint does"
  method:
    type: enum
    values: [GET, POST, PUT, PATCH, DELETE]
    required: true
    description: "HTTP method"
  path:
    type: string
    required: true
    pattern: "^/"
    description: "URL path relative to API base, e.g. /api/v1/orders"
  request:
    type: map
    description: "Request shape including body, query params, and path params"
    items:
      body:
        type: map
        description: "Request body fields"
      query:
        type: map
        description: "Query string parameters"
      path_params:
        type: map
        description: "URL path parameters"
  responses:
    type: map
    required: true
    description: "Response shapes keyed by HTTP status code"
    items:
      description:
        type: string
        required: true
        description: "When this response is returned"
      ref:
        type: ref
        description: "Reference to an entity or error component"
      refs:
        type: ref_list
        description: "Multiple component references (for 4xx with multiple error types)"
      shape:
        type: map
        description: "Inline response shape if not referencing a component"
  auth:
    type: enum
    values: [required, optional, none]
    required: true
    description: "Authentication requirement for this endpoint"
  rate_limit:
    type: string
    description: "Rate limiting rule, e.g. '10 req/sec per user'"
  idempotency:
    type: string
    description: "Idempotency strategy for non-GET requests"
```
