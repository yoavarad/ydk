# Infrastructure

Terraform infrastructure for this application, generated by ODK.

## Quick Start

```bash
# Bootstrap state management (run once)
cd infra && bash bootstrap.sh

# Initialize and plan
terraform init
terraform plan

# Apply changes
terraform apply

# Deploy application
cd .. && bash deploy.sh
```

## Structure

- `infra/` - Generated Terraform files
- `deploy.sh` - Deployment automation
- `Dockerfile.backend` - Backend container image

## Environment Variables

Set `TF_VAR_db_password` before running terraform commands:

```bash
export TF_VAR_db_password="your-secure-password"
```
