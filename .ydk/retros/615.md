Layer B ComponentScanner now runs in `ydk spec verify` with structured output (purpose `layer-b-scan`), per spec narrative, and its requests join the reviewer handoff; `ydk component scan` runs it standalone (the docs already described that command). CheckpointGenerator uses the `checkpoint` route, `task done` writes `proofs/<id>/checkpoint.md` and adds a "Review guide" PR section sharing the single exit-3 handoff with the AI plugins, and `ydk task checkpoint <id>` prints it. `archive-done` now passes the compaction provider to TaskCompactor.
