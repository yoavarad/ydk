### Template suggestions
- Epic completion detection workflow: check task status → auto-close if final → generate completion event → trigger retro requirement
- Retrospective documentation process: block new task start → prompt for retrospective → save to .ydk/retros/<epic>.md → mark retro-done flag
- Stage advancement template: verify prerequisites → execute transition → log outcomes (success or failure) → emit user feedback
- Warning/diagnostic template: identify issue condition → generate doctor warning → offer config override option → document user choice

### Rule suggestions

- All stage transitions must be explicitly logged; never silently fail or swallow errors
- Epic completion must trigger automatic closure of child stories and tasks with user notification
- Retrospective data must persist to file system under .ydk/retros/ with epic name + markdown format
- Config opt-out mechanisms should be available for all blocking behaviors; document user's choice
- Stage 03→04 advancement requires both close/sync completion AND explicit epic completion trigger
