### Patterns
- Go verification: `X/...` patterns now work in go-test `coverage_packages` and warn on zero matches (477). `race: auto` drops `-race` when cgo or a C compiler is unavailable (478).
- Windows hygiene: manifests and the verification cache are read and written as UTF-8, and an undecodable cache counts as a miss (479). Ruff PLW1514 now enforces explicit encodings across 29 files (480). Generated files and init hook scripts are written with LF (481).
- Upgrade paths: `.ydk/cache/` is ensured in `.gitignore` (482), `ydk ci init` regenerates unmodified generated CI files after config changes (483), and stale `.ydk/schemas` get an upgrade path plus a warning for undeclared manifest fields (484).
- Pack configurability: pack init answers can be passed via `--answer KEY=VALUE` and `ignition.init_answers` (486), and ignite warns when Go deps raise the go.mod `go` directive, with an optional `go_version` answer (488). The go-http-service Dockerfile no longer writes `/etc/ssl/certs` when the runtime image is swapped (487) and deploy.sh picks the helm rollback flag by Helm major version (507).
- TODO tracking: Go TODO markers record the enclosing func or receiver (485), ignition records `component_refs` on TODOs (508), and auto-assign matches on `component_refs` intersection before the path heuristic (509).
- Task CLI validation: create-batch validates `component_refs` and story refs (503) and normalizes string-form refs and acceptance (504). `spec_refs` resolve consistently (502), validate-dag normalizes epic/story IDs (506), and validate-dag and component-coverage accept `--from batch.yaml` (505).
- 515 fixed `check_dependencies` ignoring dependency type, which blocked `task start` on `related` deps that `task ready` allowed. The same bug hit epic 516 (tasks 520, 521).

### Template suggestions
- Bug-fix task templates for field reports should name the source issue and the platform (Windows, cgo-less, Helm major version) so reviewers can reproduce.
- Tasks touching file IO should state the encoding and newline expectation in acceptance criteria.

### Rule suggestions
- Keep ruff PLW1514 enabled so new `open`/`read_text`/`write_text` calls must pass an encoding (480).
- Default-value checks that depend on the host toolchain (cgo, Helm version) need a fallback path and a test for the unavailable case (478, 507).

### Summary
Epic 472 shipped 21 tasks in 5 stories (21/21 done) hardening the Go bootstrap path of ydk 1.6.0: go-test plugin robustness, UTF-8/LF file IO on Windows, init and CI upgrade paths, pack configurability for go-http-service, and task CLI, todo and catalog field-bug fixes. Main risk carried forward: the `--from` batch validation (505) and ref normalization (503, 504) are new CLI surface that earlier batch files may not have exercised.
