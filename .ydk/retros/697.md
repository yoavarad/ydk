### Rule suggestions
- Never use `git stash` in parallel worktrees: the stash stack is shared by all of them. Set work aside with a WIP commit.
- Merge commits need conventional titles (`chore(merge): ...`); git's default "Merge ..." title passes `cz check`.
- When several parallel PRs touch the same test file, expect add-at-same-spot conflicts and keep both sides.
- Do not close an epic while its follow-up tasks are open; the retro gate will flag it.
